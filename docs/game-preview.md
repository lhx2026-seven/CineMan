# 第二頁：本週營運配置版型

沿用靜態伺服器即可，沒有新增套件或服務。首頁按「選擇」再按「確定」，經由布幕轉場進入 `game.html?cinema=C01`（C01–C05 對應五家戲院）。可使用此網址直接審閱各家版型；缺少或無效 cinema 會返回選擇頁，不預選戲院。首頁最新配色與使用者改成一致的「選擇」按鈕文案均保留。

## 已具備的版型與操作

介面採緊湊營運面板：外觀圖縮為識別縮圖、日期移至工具列，保留首頁品牌標題位置；預算及定價改為標籤／數值資料列，固定舊片與報表使用較薄的唯讀列，縮小片單、櫃台圖片、標題與內距。手機可操作欄位仍維持至少 44px 高。尚未提供正式唯讀欄位名單，因此不擅自鎖定目前可試填項目。

PC 與手機共用三個頁籤：預算配置、定價、選片。財務報表固定放在外觀照下方、頁籤上方；採收入／支出分欄、收入與費用明細、本週合計及損益的表格，非適用欄以「·」表示，待結算金額以「—」表示。一次只顯示一個設定頁籤面板，標籤列在捲動時固定於頂端；切換不重建表單，欄位、勾選與主打片占比保持。支援左右方向鍵、Home／End 與標準 tab／tabpanel 語意。上方外觀及下方櫃台與下一週為共用區。重新整理預設回預算配置，但已填內容會還原。

- 與首頁位置相同的 CineMan 品牌標題，以及所選戲院相同的外觀圖。
- 租金、硬體維護、人力、稅四項每週預算欄位，暫以 NT$ 金額呈現。
- 全票、優待票、早場票、爆米花、飲料的定價。
- 海報及公仔分別勾選才展開印量／製作量及售價；取消勾選會停用欄位，保留已輸入內容供再次啟用。
- 兩部本週新片占位，單選主打片後啟用場次占比（0–100%，每格 5%；初始顯示值 50% 僅為配置介面值）。三部固定舊片不提供調整控制項。
- 財務報表的收入、支出、損益與分項列，數字均為「—／待設定」，不計算或杜撰結果。
- 五張對應各戲院風格的售票櫃台 WebP，位於 `assets/cinemas/counters/`，寶宮採寬景構圖並保留水晶吊燈的展示高度；吊燈位於售票口正前方大廳中軸的天花板，左向右斜拍時僅下半部從畫面上緣入鏡，其餘按緊湊版面裁切。布洛威、YLC、公會堂採較明亮的中性白光，世紀維持原圖。
- 「下一週」在未設定本週主打片前為 disabled，顯示灰色不可按樣式與提示；只瀏覽選片頁籤或改其他設定不解鎖。設定任一主打片後才能開啟結算尚未開放的預覽對話框，不推進週數或產生營運結果。有效的已存選片配置可在重整後保持解鎖，各戲院分別判定。
- 各戲院獨立保存本機配置（`cineman.gameDraft.Cxx`），重整可還原；沒有後端／跨裝置同步。瀏覽器禁止儲存時可操作本頁，但明確提示不能保存。
- 布幕轉場支援減少動態效果；返回首頁依原規則保持無預選。

## 驗證

已在瀏覽器驗證首頁選擇到第二頁的實際轉場、品牌位置、五家外觀與櫃台圖對應、商品開關、主打片與占比、三部不可調整舊片、本機保存與還原、戲院間配置隔離、未提供財務公式時不產生結果，以及「下一週」預覽提示。已檢查 320、390、768、1440px 寬度（包含商品設定展開）無水平溢出，並驗證瀏覽器儲存不可用時仍可進入及操作。

報表／選片門檻版已驗證 320、390、768、1440px：報表在切換三個頁籤時保持顯示、欄位無水平溢出、未選片時原生按鈕與 click handler 均阻擋進入下一週、設定主打片才解鎖、有效配置還原後解鎖，且不跨戲院套用選片狀態。

## 載入與轉場

卡片提供 640px WebP 衍生圖與 srcset；原始高解析圖保留作高密度備選。遊戲外觀縮圖沿用同一衍生圖，售票口另提供 960px 版本，依顯示寬度與裝置像素比選擇。十張 640px 圖合計 423,556 bytes，相較原圖 2,955,256 bytes 減少約 86%。

玩家手動選擇後才預載遊戲 CSS／JS、預取該戲院的遊戲文件；省流量模式不預載。不預載五家售票口。轉場關幕約 450ms、開幕約 450ms，外觀解碼最多等待 350ms，轉場期間暫停卡片漂浮動畫。保留減少動態效果設定及直接進入遊戲頁的支援。

Chromium 本機 390／1440px、2x 像素比測試：確定到布幕移除約 1.1 秒，卡片及外觀使用小圖、無資源載入錯誤，選片門檻正常；模擬圖片延遲失敗仍會解除布幕。此數字為本機測試，非 GitHub Pages 網路速度保證。

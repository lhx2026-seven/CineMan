# 第二頁：本週營運配置版型

沿用靜態伺服器即可，沒有新增套件或服務。首頁按「選擇」再按「確定」，經由布幕轉場進入 `game.html?cinema=C01`（C01–C05 對應五家戲院）。可使用此網址直接審閱各家版型；缺少或無效 cinema 會返回選擇頁，不預選戲院。首頁最新配色與使用者改成一致的「選擇」按鈕文案均保留。

## 已具備的版型與操作

- 與首頁位置相同的 CineMan 品牌標題，以及所選戲院相同的外觀圖。
- 租金、硬體維護、人力、稅四項每週預算欄位，暫以 NT$ 金額呈現。
- 全票、優待票、早場票、爆米花、飲料的定價。
- 海報及公仔分別勾選才展開印量／製作量及售價；取消勾選會停用欄位，保留已輸入內容供再次啟用。
- 兩部本週新片占位，單選主打片後啟用場次占比（0–100%，每格 5%；初始顯示值 50% 僅為配置介面值）。三部固定舊片不提供調整控制項。
- 財務報表的收入、支出、損益與分項列，數字均為「—／待設定」，不計算或杜撰結果。
- 五張對應各戲院風格的售票櫃台 WebP，位於 `assets/cinemas/counters/`，生成圖原生比例 2:1；網頁按版面裁切。
- 「下一週」目前顯示結算尚未開放的對話框，不推進週數或產生營運結果。
- 各戲院獨立保存本機配置（`cineman.gameDraft.Cxx`），重整可還原；沒有後端／跨裝置同步。瀏覽器禁止儲存時可操作本頁，但明確提示不能保存。
- 布幕轉場支援減少動態效果；返回首頁依原規則保持無預選。

## 尚未定義／刻意未實作

片名、電影資料、正式海報、初始預算與定價、成本與稅率規則、需求及上座率、影廳排片限制、分帳及財務公式、每週結算及完整遊戲進程。沿用三份 Excel 的規則資料；本頁沒有擅自生成影廳配置或解讀 normal 的分布參數。

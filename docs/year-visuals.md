# 年份視覺彩蛋

2022年保留上方外觀圖與頁尾售票口圖。2023–2024年上方改用首頁同家戲院的landscape/*-interior.webp。2025 W1起上方改為tickets/*-ticket.webp，之後年份持續使用票圖。2024 W1起頁尾改用projection/*-projection.webp，視角為從前方看向觀眾席後牆與放映窗；之後年份頁尾持續使用。

年度會議仍歸原年度，點「開始下一年度」後才切換。圖片依遊戲年份推導，不新增存檔欄位；舊存檔讀取同樣適用。完成讀取年份才指派圖片URL，避免先載2022素材再替換；dataset.asset防止每週更新時重複指派。錯誤復原仍可顯示圖與重試控制，不新增等待圖片解碼的轉場阻擋。

五張後方視角以各自首頁內裝為參考生成，原圖1774×887；正式圖與960px版均轉為WebP（quality82）。手機srcset版本約39–73KB；CSS object-position:center 30%保留短頁尾中的放映窗。2022–2023售票口原有構圖不變。

驗證：tests/year-visuals-browser.cjs測試五家、390／1440px、2022→2023、2023年度會議→2024 W1、存檔重整、實際圖片載入成功及不下載過期圖。tests/entry-performance-browser.cjs涵蓋進場、延遲讀檔、失敗復原與重試。


電影票共有五款：寶宮黃紙紅印的直式復古全票、世紀橘色懷舊票、布洛威紫色現代票、YLC藍銀票、公會堂綠色藝文票。寶宮及世紀依參考老票券不印片名，其餘三家片名暫維持CineMan；票面文字以繁體中文為主。原圖1774×887，640px響應式WebP約35–47KB，quality85；以object-fit:contain完整顯示票面與票根，避免桌面較高主圖區裁掉文字。票面是視覺彩蛋，不依當局票價、上映片或座位動態更改。

year-visuals-browser另涵蓋2024年度會議保留內裝、進入2025W1即時切換、重新整理直接載票圖且不下載過期內裝圖、2026仍使用票圖，以及五家手機／桌面完整顯示樣式。

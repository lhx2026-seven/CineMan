# 年度會議

每年仍為50個營運週。W50完成選片後，頁尾「年度會議」先結算W50票房、餐飲、周邊及到期的空間收入，再進入虛擬W51。會議年報因此包含本年50週營運收入。營運表單及頁籤隱藏；LOGO回首頁、存檔及重新整理仍可用。

虛擬W51是年末階段，不是第51個營運週：不抽新片、不推進上座率衰退、下片或系列間隔。存檔保留year/week=當年/50及annualMeeting.settled=true，畫面及首頁存檔標籤顯示「YYYY年度會議」。既有version 1會議存檔先補做年末結算，不跳過W50。

會議固定四區：左上實際累計年度損益SVG走勢圖、右上「戲院名稱YYYY年度損益摘要」及年度收入／支出／損益、左下「年度票房TOP 5」、右下股東或董事長回應。手機同樣使用兩欄四格。收入只報合計；收入合計採拆帳後票房加餐飲、周邊與其它收入；支出已合計全部已記錄項目，並列稅前淨利；年度損益扣除依financial-totals.md計算的所得稅，5%部分非正數時免繳，2022–2025仍另計7.5%娛樂稅，其負值可抵減。

TOP 5以本年各片拆帳前票房加總排序，包含一般場、特別場、已下檔及special片；只顯示排名與片名。零票房不列入，同票房依movie ID排序。世紀仍不公開單片數據，該格顯示「本院僅顯示合計票房」。

每局每年以獨立種子50%選股東、50%選董事長；刷新或續玩不重抽。回應庫未提供，暫以省略號預留。

頁尾「開始下一年度」只推進一次電影生命週期，抽取翌年W1新片並開放年度票價設定，不重複結算W50。新年度報表從0開始。年末新收據以accountingYear歸入結束年度；舊存檔已入帳收據維持原年度，不重算歷史金額。

驗證：tests/virtual-year-close.cjs、annual-meeting-browser.cjs、annual-ticket-lock-browser.cjs、box-office-browser.cjs、second-run-revenue-visibility-browser.cjs。


## 實際損益走勢

原系統保存各筆收入／支出及入帳日期，沒有逐週年度損益快照。financial-totals.js/annualTrend從現存收據按日期重建當年度W1至W50的累計值，另加年度會議最終結算點（虛擬第51週，圖上不另標週次），使用與年報相同的預扣稅金公式。曲線末端應等於右上損益摘要及年報年度損益。

包含拆帳後票房（含片租、保底差額）、餐飲、周邊、其它收入，及全部營運費用、租金、管理費、不動產稅、公共事業帳單。依at／bookedAt／week及accountingYear／year計入，不能用本週收支直接相加取代年度預扣稅金重算。W50的跨年入帳歸本年結算；真正下一年度收入不混入。

圖表為簡潔折線，不顯示標題或X軸週次；Y軸僅顯示向外取整的上界、0、下界，金額加千分位、不縮寫成萬／億，滑鼠指向各週圓點可查看確切金額，整張圖提供無障礙文字摘要。負值、跨過零及全年度相同數值均正常顯示，不產生假起伏。沿用手機兩欄四格。資料依現存帳本與現行年度稅則重建，不聲稱還原缺少的舊版歷史資料或過去稅則版本；不為圖表補造交易。

只在會議畫面需要時建立51格累計資料，單次掃描各帳本、不為每週重新掃全歷史，也不新增每週存檔欄位、外部圖表依賴、計時器或圖片下載。

測試：tests/financial-totals.cjs涵蓋各收入／支出、預扣稅負值抵減、2026差異、跨年結算與平線；tests/annual-meeting-browser.cjs驗證圖表終值等於年報、MIN/MAX、51個點、手機／電腦及讀檔、年度切換。


Y軸刻度以當年最大絕對損益的量級取約兩位有效數的共用步幅，上界向上、下界向下取整並包含0。例如315萬／-152萬→3,200,000／0／-1,600,000；1280萬／-552萬→13,000,000／0／-6,000,000。同號損益時0即為其中一側邊界，不重複顯示0；全0時以±1提供有效繪圖範圍，折線仍為0，不製造起伏。無障礙摘要與圓點提示保留實際金額，圖軸取整不更改損益或結算值。


年度會議四格以grid-auto-rows:1fr自動等高，由文字內容及最小160px高度決定。圖表放在同尺寸容器內填滿，ResizeObserver僅在容器尺寸變動時依寬高重算SVG的viewBox及Y座標；文字與圓點保持比例，不用preserveAspectRatio=none拉伸，也不以空白補足固定16:9圖。再次render時先斷開舊observer，不進行定時輪詢。瀏覽器測試另覆蓋四格等高、回應文字動態加長／還原及viewBox比例與實際容器一致。

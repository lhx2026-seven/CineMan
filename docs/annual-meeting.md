# 年度會議

每年仍為50個營運週。W50完成選片後，頁尾「年度會議」先結算W50票房、餐飲、周邊及到期的空間收入，再進入虛擬W51。會議年報因此包含本年50週營運收入。營運表單及頁籤隱藏；LOGO回首頁、存檔及重新整理仍可用。

虛擬W51是年末階段，不是第51個營運週：不抽新片、不推進上座率衰退、下片或系列間隔。存檔保留year/week=當年/50及annualMeeting.settled=true，畫面及首頁存檔標籤顯示「YYYY年度會議」。既有version 1會議存檔先補做年末結算，不跳過W50。

會議固定四區：左上SVG簡報示意、右上「戲院名稱YYYY年度損益摘要」及年度收入／支出／損益、左下「年度票房TOP 5」、右下股東或董事長回應。手機同樣使用兩欄四格。收入只報合計；收入合計採拆帳後票房加餐飲、周邊與其它收入；支出已合計全部已記錄項目，並列稅前淨利；年度損益標示「待所得稅」，不假設未提供的稅額為0。

TOP 5以本年各片拆帳前票房加總排序，包含一般場、特別場、已下檔及special片；只顯示排名與片名。零票房不列入，同票房依movie ID排序。世紀仍不公開單片數據，該格顯示「本院僅顯示合計票房」。

每局每年以獨立種子50%選股東、50%選董事長；刷新或續玩不重抽。回應庫未提供，暫以省略號預留。

頁尾「開始下一年度」只推進一次電影生命週期，抽取翌年W1新片並開放年度票價設定，不重複結算W50。新年度報表從0開始。年末新收據以accountingYear歸入結束年度；舊存檔已入帳收據維持原年度，不重算歷史金額。

# 年度會議

每年50週。玩家在W50完成營運選片後，底部「年度會議」按鈕先開啟事件區的會議畫面，不進週、不結算W50、不改動電影／活化收入收據。週次維持該年W50，營運表單與頁籤暫停互動，年報自動打開；LOGO回首頁及存檔仍可用。

會議使用一張小型SVG簡報示意，不繪製實際財報圖表。文字只呈現年度已入帳收入合計、年度支出總額及年度損益，不展開票房、空間活化等收入細項。收入總額包含已入帳拆帳前票房、餐飲、海報、公仔及空間活化收入，但不在會議顯示細項。由於拆帳後、支出及完整損益公式未完成，明確表示支出及年度獲利待結算，不把缺值當0、不推論獲利或虧損。

依原入帳制度，W50營運票房與週結活化收入於翌年W1入帳，因此不放入本次會議的當年度摘要；月結收入依實際入帳年度計算。這個功能不更動原會計口徑。

每局每年用獨立種子50%選股東、50%選董事長。annualMeeting快照保留version/year/role，刷新、首頁Continue不重抽，也不消耗新的電影／收入隨機值。回應庫未提供，回應區先顯示角色與省略號，沒有捏造評語或事件效果。

「開始下一年度」位於頁尾原本的「下一週」按鈕位置，會議區不另放按鈕；點擊才執行一次原本的W50→翌年W1結算；按鈕忙碌時禁用，已有票房的重複結算保護仍生效。成功後清除會議狀態，事件區恢復「本週大事」，營運解鎖、年度W1票價開放。若結算失敗，維持W50會議並可重試。

程式：annual-meeting.js（角色、摘要、顯示），game.js（流程及快照），weekly-events.js（事件區復原），assets/annual-meeting.svg（簡報圖）。Tests: tests/annual-meeting.cjs, tests/annual-meeting-browser.cjs；並驗證box-office-browser、annual-ticket-lock-browser。

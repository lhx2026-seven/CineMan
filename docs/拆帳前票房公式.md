# CineMan 拆帳前票房公式總表

此文件按目前實際程式整理，涵蓋一般場、特別場、上座率、排片及下檔例外。票房金額單位為 NT$；上座率及場次占比以小數計算（50%＝0.5）。加減「百分點」與乘法不同，例如40%＋50個百分點＝90%。

對應程式：`box-office.js`、`movie-rules.js`、`parameter-rules.js`、`game.js`。未實作的拆帳後、餐飲、週邊、成本與稅金公式不包含在這份已生效公式內。

## 1. 主公式與取整順序

對每一部仍上映、且通過寶宮留片規則的電影：

```text
單片單日一般場人次
＝四捨五入（最終上座率 × 總座位數 × 6 × 單片場次占比）

單片單日一般場票房
＝單片單日一般場人次 × 座位加權平均票價

單片單週拆帳前票房
＝四捨五入（單片單日一般場票房 × 3
            ＋該片本週所有特別場票房）

全戲院單週拆帳前票房
＝各片單週拆帳前票房加總
```

先將人次取整，再計票房；平均票價可有小數，最後單片單週票房才四捨五入到元。每部片取整後再加總，不是先把全戲院未取整金額加總。每日6場、一週乘3目前都是固定值。

只有一部片存活時，若玩家主打占比不足100%，程式仍採玩家設定比例，不自動補成100%。

## 2. 平均票價

設全票為 F：學生軍警票＝F−30；早場優惠票＝F−60；愛心票＝F×0.5。

| 戲院 | 一般廳計算用平均票價 |
|---|---|
| 寶宮、布洛威、YLC | `[F ＋ ((F−30)＋(F−60)＋F×0.5)／3]／2` |
| 世紀：一票單片 | 玩家設定票價／1 |
| 世紀：一票二片 | 玩家設定票價／2 |
| 世紀：一票看到底 | 玩家設定票價／（影廳數×2） |
| 公會堂 | 只計全票 F；愛心票不參與平均 |

若有特殊廳（EXTRA），其座位採玩家設定的該種特殊廳票價，而非一般廳平均票價：

```text
座位加權平均票價
＝Σ（每廳座位數 × 該廳適用票價）／總座位數
```

同一特殊廳種類若有多個實體廳，每廳分別按自己的座位數加入加權。此平均票價套用於一般場；特別場另用該場的單一票價。

## 3. 原始上座率：一般 tier

首週皆以1個百分點為步長抽取，且包含區間端點：

| Tier | 首週原始上座率 |
|---|---|
| hit | 90%機率選50%～79%；10%機率選80%～100%；各區間內等機率 |
| bomb | 1%～10%，等機率 |
| average | 1%～50%，等機率 |

同一局、同片、同上映日期使用固定種子；刷新及繼續經營不會重新抽取。

設抽出的首週值為 B，電影自身上映年齡為 W1、W2……：

| 上映年齡 | 當週原始上座率 |
|---|---|
| W1 | B |
| W2 | B×（1−隨機0%～50%）＝B的50%～100% |
| W3 | B×（1−隨機50%～75%）＝B的25%～50% |
| W4 | B×（1−隨機50%～99%）＝B的1%～50% |
| W5起 | 固定1%，只適用仍未下檔的片 |

各週減幅以1個百分點為步長，分別從首週值計算，並非從前一週繼續扣，因此允許反彈。非主打新片也算正式上映，同樣開始計齡、衰退及系列解鎖倒數。

## 4. 普通片的上座率調整順序

```text
當週原始上座率
→ 乘區位初始係數
→ 套區位加成／減成
→ 限制在0%～100%
→ 扣除各項票價懲罰
→ 再限制在0%～100%
→ 公會堂：hit ×0.5、average ×1.5，再限制在0%～100%
→ 套排片懲罰（依戲院作用於主打或非主打，如符合）
＝最終上座率
```

`location_weight`、`ticket_price_weight`目前已實作為上述上座率調整，不會在票房式再重複相乘。special tier略過本節所有調整，見第7節。

### 4.1 區位

| Location | 第一優先：初始係數 | 然後套用的規則 |
|---|---:|---|
| LOC01 都會區舊城 | ×1.00 | 寶宮、公會堂＋50個百分點 |
| LOC02 都會CBD | ×1.00 | hit ×1.75 |
| LOC03 都會中心社區 | ×0.80 | 世紀＋25個百分點 |
| LOC04 城郊社區 | ×0.90 | hit ＋50個百分點 |
| LOC05 衛星城市 | ×0.80 | 影廳數＜4且為hit，×1.5 |
| LOC06 新市鎮 | ×0.60 | bomb、average再×0.5 |
| LOC07 中型城市 | ×0.70 | average −25個百分點 |
| LOC08 小城鎮 | ×0.60 | 普通片再×0.5 |

條件未符合則只套初始係數。例如普通hit在LOC06的W5原始1%會成為0.6%；average則成為0.3%。區位加減仍可能讓普通片W5的實際上座率高於1%。

### 4.2 票價懲罰

各項可累加；價格「等於」門檻不扣：

| 條件 | 扣除上座率 |
|---|---|
| 寶宮、布洛威、YLC全票＞350 | −50個百分點 |
| 世紀選一票單片 | −50個百分點 |
| 公會堂全票＞200 | −5個百分點 |
| 任一戲院有特殊廳票價＞500 | −（超過500元的特殊廳數／全部影廳數） |

最後一項以比例扣除百分點，例如2廳／10廳＝扣0.2＝20個百分點。僅計超過500元的實體特殊廳，同種類多廳分別計數。

注意：特殊廳「票價」在收入端按座位數加權；特殊廳「票價懲罰」目前按廳數占比，作用於該普通電影全戲院的上座率，並非只扣特殊廳座位的人次。

公會堂的 tier 調整作用於每部 hit／average（含主打、非主打），在區位及票價調整後計算；bomb不變，special維持自身固定規則。例：票價調整後60%，hit變30%，average變90%；average原為80%則乘1.5後以100%計。

### 4.3 排片懲罰

- 世紀：主打占比＞60%，每部非主打普通片的最終上座率再×0.5；剛好60%不觸發。
- 寶宮：主打占比＞80%，僅留1部非主打，該普通片最終上座率再×0.5；剛好80%不觸發。
- 布洛威、YLC：主打占比＞80%，只有主打普通片的最終上座率再×0.75；剛好80%不觸發，非主打片不受此條影響。特別場仍使用原始上座率，不套此懲罰。
- 影廳數＞7且主打占比＞50%：只有主打普通片最終上座率再×0.25；剛好7廳或50%不觸發。與布洛威／YLC的＞80%懲罰相乘，兩者同時符合時合計×0.1875；非主打片與特別場不受此條影響。
- special tier不受上述排片上座率懲罰，但仍受寶宮片數上限及強制下檔規則約束。

## 5. 場次占比與留片規則

設主打比例為 S，存活的非主打片共 N 部：每部非主打比例＝（1−S）／N。已下檔／本週強制排除的片不參與分配；若沒有可選新片或可延用主打、也沒有主打選擇，存活片平均分配100%。

- 寶宮、布洛威、YLC、公會堂：拉條每格＝100%／（6×廳數）。
- 世紀：每格＝100%／（2×廳數）。此處只改占比刻度，每日人次式仍乘6。
- 每週預設均為100%的前一格。
- 布洛威、YLC、公會堂禁止設100%，最高為前一格；寶宮、世紀仍可100%。
- 第二週起可手動延用「上週主打」，每片只能延用一次，結算時才消耗；不重設上映日期或衰退。必須仍上映，兩部新片仍照常抽入。

### 寶宮一般情況：最多4部

1. 保留本週兩部新片（若片池不足則按實際抽入數）。
2. 其餘仍上映舊片，按上週單週票房由高到低排序；同票房則較近期上映優先，再以movie ID決定。
3. 留第一名舊片；第二名舊片若上週票房至少2,000元，且達最高舊片票房50%，也保留。兩門檻均含等於。
4. 玩家若手動延用舊片主打，該片保護為第一個舊片名額；另一個舊片名額取其餘最佳者，仍需滿足對最高舊片票房的50%及2,000元條件。
5. 首週或無上週收據時以日期、ID決定首個舊片名額，不增加第二個舊片名額。不復活已下檔電影。

### 寶宮主打＞80%：最多2部，優先於上述規則

留主打與同週上映的另一部片；不存在同週搭檔時，留最新的其他存活片（同日以ID決定）。首週預設舊片不算當週新片的同週搭檔。若延用舊片主打，優先找該舊片原上映週的搭檔。

兩種寶宮規則排除的其他片，**當週一般場及特別場票房全部為0**，並記錄永久下檔，不只停止下週上映。

## 6. 特別場

只開放寶宮、布洛威、YLC，每週最多5場。額外場次，不扣一般場占比；每場基準100人，不受實際影廳座位數限制。

設該片當週「原始上座率」為 R、該場單一票價為 P：

| P | 特別場人次 |
|---|---|
| 400 | 固定100人 |
| 410～500 | 四捨五入（100×R） |
| 510～600 | 四捨五入（100×R×0.7） |

```text
單場特別場票房＝已取整的特別場人次×P
```

票價步長10元。特別場不套區位、票價或非主打減半懲罰，不乘3；每場只計一次。同片多場逐場算人次後加總。被寶宮強制排除的片，其特別場也歸0。

## 7. 六部 special tier

以下「原始上座率」直接作為最終上座率：不套區位初始係數、區位加減、票價扣減、非主打減半。但仍乘實際座位數、6、場次占比、平均票價與每週3天，並加特別場；**不是固定票房金額**。

| 電影 | 上座率 | 正常下檔規則 |
|---|---|---|
| MV0001 魔猴 | 固定50% | 遊戲W3起，每週90%機率下檔 |
| MV0002 恐怖速食店 | 固定50% | 遊戲W3起，每週90%機率下檔 |
| MV0003 酆都 | 固定10% | 遊戲W2必下檔 |
| MV0503 銀幕不熄 | 該片W1～W4：50%、70%、90%、99%；W5起50% | 該片W5起每週50%機率下檔 |
| MV0504 豪情四兄弟 | 該片W1～4：100%；W5～8：90%；W9～12：50%；W13起1% | 該片W13起每週90%機率下檔 |
| MV0505 艾蜜莉的異想世界 | 該片W1～4：100%；W5～8：80%；W9～12：60%；W13起1% | 該片W13起每週90%機率下檔 |

MV0001～3只作開局舊片；單廳戲院開局不加入這三部。MV0503限2026抽入，該片上映第四週觸發影迷連署事件；事件目前不額外改票房、土地或稅金。

上述保護不抵抗「上週票房不足2,000」或寶宮強制留片上限。

## 8. 下檔與零票房

- 任一仍上映片上週單週票房＜2,000元，本週強制下檔。看的是含特別場的已取整單片單週金額，**不是累積票房**；等於2,000元不觸發。
- 新片沒有前週收據，不當成零票房；舊存檔無歷史收據時不捏造過往票房。
- 一般tier的W5起每週90%隨機下檔；留下則原始上座率1%。special另依第7節。
- 下檔後不分配場次，也不能再延用或辦特別場；歷史票房不刪除。
- 上週票房很好不代表一定保留：仍可能隨機下檔，或被寶宮高主打占比規則排除。

## 9. 財報入帳與累積

```text
本週營運所產生的票房 → 下一週入財報
單片累積票房＝已入帳的該片各週票房加總
年報拆帳前票房＝該入帳年度的所有週票房加總
```

2022 W1尚無入帳收據，週報顯示0。每年固定50週；W50營運票房在隔年W1入帳，歸隔年年報。既有已入帳收據不因改參數而回算，重載也不重複結算。

拆帳後票房尚未設定公式，週報、年報皆保留欄位並顯示「—」。其他尚未接入的計算參數不會自動套入拆帳前票房。

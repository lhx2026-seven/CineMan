# 每週營運支出

按「下一週」時，用本週預算及實際營運紀錄結算五項支出，與本週營運收入於隔週列入報表：

| 財報項目 | 公式 |
|---|---|
|人事|人力預算×1.2＋實際特別場場數×500|
|商品成本|餐飲成本＋本週海報印製量×海報售價×0.1＋本週公仔訂製量×公仔售價×0.2|
|硬體維護|本週硬體維護預算|
|行銷宣傳|本週行銷宣傳預算|
|其它費用|本週雜支＋實際特別場場數×5,000＋未另列名目的事件支出|

特別場計算實際通過排片規則、完成結算的場次；未選片欄位、未開放特別場的世紀／公會堂、強制排除電影均不計場次。即使某場觀影人次四捨五入為0，確實舉辦仍計一場。票房收據保存specialSessionCount（0～5），不從觀看人次或表單預設場數倒推。

製作量使用周邊結算收據的produced；未開賣的未生效輸入、庫存續賣、報廢舊庫存不再算製作成本。對當週新製作量計費，無論賣出與否；使用當週該品項售價。保留中間精度，每列最終四捨五入至元。

週報顯示本次已結算金額，年報累計該年支出。修改拉條只影響後續營運，歷史支出不回算。租金、管理費、不動產稅仍依各自出帳週列計，不重複放進這四列；片商扣款已列拆帳後票房，不另扣一次。

W50結算進虛擬年度會議，五項支出歸結束年度；點「開始下一年度」不重複結算，翌年W1的週／年支出從0開始（其它即時出帳項目另計）。營業利益、稅前淨利及年度會議收支合計已按financial-totals.md連動；年度損益僅待所得稅公式。公共事業帳單已依utility-bill-expense.md連動。

快照operatingExpenses保存版本、結算週、每週原始預算、特別場次、新製作量／售價、五項金額與總額；驗證金額、週次、年度，防止重複入帳。舊存檔沒有完整歷史預算，因此從下次營運結算開始記錄，不以目前預算回填歷史支出。

程式operating-expenses.js、box-office.js、game.js；tests/operating-expenses.cjs、operating-expenses-browser.cjs、annual-meeting-browser.cjs與既有票房／進場測試。

版本2新增其它費用；舊版1已結算紀錄保持原值，缺少其它費用按未記錄的0處理，不回填歷史雜支。事件費用入口、一次性扣款及所需資料見financial-totals.md。

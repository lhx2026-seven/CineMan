# 不動產稅

僅自有場地（realEstateTaxActive=true）繳納；公會堂自有場地免稅，承租場地免繳；每年W46出帳一次。每年50個營運週，因此絕對週次為46、96、146…；虛擬年度會議不多計一週或多出帳單。

金額＝四捨五入至元（總座位數平方 × 區位係數）。此次對照表每個區位只有一個數值，因此直接使用固定係數，不另抽亂數：

| 區位 | 係數 |
|---|---:|
|LOC01|1|
|LOC02|1.1|
|LOC03|0.9|
|LOC04|0.8|
|LOC05|0.7|
|LOC06|0.7|
|LOC07|0.8|
|LOC08|0.6|

保留計算座位數、係數及稅額；沒有場地變動事件時每年相同。公會堂自有場地稅額為0且不產生帳單；先前存檔的公會堂不動產稅紀錄於載入時同步清除，財報依新規則免稅。

週報／年報原本的「租金、管理費、不動產稅」欄位加總租金與已出帳不動產稅。W46週報顯示稅額，該年年報保留一次稅額，其它週週報為0（承租則依原租金週期）。此項屬場地支出，不放入年報下方另列的所得稅「減：稅」。管理費、其它未接支出與完整損益仍待設定，不以部分金額冒充完整總額。

快照propertyTax保存版本、局與戲院ID、權屬、區位、座位數、係數、固定稅額、已處理週次及帳單。舊存檔首次載入會補建截至當週已到期帳單；續玩或重新整理不重複出帳，也不改寫歷史收入。

程式property-tax-rules.js；測試tests/property-tax.cjs及tests/property-tax-browser.cjs，涵蓋固定係數、平方計算、四捨五入、自有／承租、W46、跨年、會議、防重扣及存檔驗證。

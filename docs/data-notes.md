# 第一層戲院選擇

啟動：`python3 -m http.server 8000 --bind 127.0.0.1 --directory /workspace/CineMan`。頁面透過 fetch 讀取 JSON，請透過 HTTP 開啟。

`assets/cinemas/landscape/` 僅保留目前頁面使用的十張圖片：每家各有 exterior（外觀）與 interior（內裝）。原始 JPG 與被取代的外觀圖已清理，可從 Git 歷史找回。

`data/cinemas.json` 轉錄使用者提供的 CinemasList.xlsx、LocationsList.xlsx、ScreensList.xlsx 第一張工作表，保留非空白欄名、原始欄名、null、布林與 normal；略過整列空白與無欄名的空白欄。共 31 筆戲院配置、8 筆地點、13 筆影廳類型。不是後端資料庫。

關聯：C01=baogong=寶宮、C02=century=世紀、C03=broadway=布洛威、C04=ylc=YLC、C05=arthouse=公會堂。cinemaID 對應 LocationsList 的 cinemaID_Cxx_applicable 欄。只有 true 顯示為適用，空白代表不適用（使用者已確認）。CinemasList 的 screens 是可選廳數，不是連續範圍；依 Excel 取代原 HTML 的概略數值。影廳類型 A/B/C/D/EXTRA 可對應 ScreensList.type，但目前不生成實際配置，也不推算座位總數。

第一層保留待選 cinemaID（localStorage: cineman.selectedCinema）及確定後的 cinemaID（cineman.confirmedCinema），可改選並再次確認；每次開啟或重新整理選擇頁都清除先前選擇與確認，不預選任何戲院；第二層與跨裝置儲存未實作。儲存不可用時仍可在本頁選擇。

使用者已確認：影廳資料以 Excel 為準；normal 代表常態分布；LocationsList 空白代表否定（不適用）。目前保留 normal 原值，不生成隨機配置。實作時仍需定義常態分布的平均值、標準差、取值範圍及離散化方式；第二層進入流程也尚待定義。原頁土地與租金敘述缺少 Excel 依據，因此不作為配置資料展示。

玩家卡片依序展示外觀圖、戲院名稱與類型及選擇鈕、內裝圖，不使用圖片切換按鈕。影廳選項與適用地點不在卡片或選擇摘要中顯示；完整規則仍保留在 data/cinemas.json，以 cinemaID 關聯。

目前使用 assets/cinemas/landscape/ 的十張 AI 重新生成圖片，原生比例 2:1、尺寸 1774×887，依照原本戲院風格重新安排入口／銀幕與座席的橫幅構圖。網頁採 WebP（quality 88），十張合計約 2.8 MiB，未使用舊版 scale 放大補償。桌面版也使用 2:1 圖片比例。

選擇頁採有限範圍的 3D 旋轉木馬，以水平弧線排列直立卡片，由左至右為公會堂 C05、世紀 C02、寶宮 C01、布洛威 C03、YLC C04。起始中央視野是寶宮，但沒有選取或聚光；選取後整組沿弧線移動，該卡片來到正中央、放大並亮起聚光，側面卡片朝內轉且向後退。使用 translateZ 與 rotateY 呈現深度，沒有撲克牌式 rotateZ 斜扇。

瀏覽支援點卡片圖片／文字、左右箭頭、鍵盤方向鍵及手機水平滑動；只有按下卡片上的「選擇」鈕才變更選擇並顯示確認框，瀏覽會收起確認框但保留先前手動選擇；到公會堂／YLC 兩端停止，不循環繞圈。手機中央卡片高度為 min(480px, 100svh - 72px)，支援減少動態效果偏好。卡片三個內容分區、文案與五家配色保留。

圖片微調：布洛威外觀改為帶有使用年歲的商業辦公大樓與多幅巨型電影海報；YLC 外觀保留原建築，在屋頂附近加上 YLC 發光招牌。兩張使用 -v2.webp 新檔名；index.html 的 app.js 加上版本參數以避免沿用舊程式快取。部署透過 GitHub Pages 的 main 分支自動執行；推送成功與部署成功需分別確認。

世紀外觀更新為一樓角落售票口、另一半是帶小張海報櫥窗的內凹門廊，二樓改為三扇小窗，使用 century-exterior-v2.webp。已刪除十張舊 JPG 與三張被新版取代的外觀 WebP，保留十張使用中圖片；未重寫 Git 歷史。

選擇確認區位於頁首與戲院卡片之間，顯示「要進入 XX 戲院大展身手？」與確定鈕；玩家選取後留在舞台查看卡片浮起與聚光，上方確認區同步更新，確定後保存狀態、改選時清除先前確認。第二層尚未實作，確定鈕目前不導向新頁面。頁首保留 CineMan 與金色細線裝飾副標「享受自己擁有一家電影院的美麗與哀愁」。

起始頁永遠無預選戲院，確認區預設隱藏；不從 localStorage 還原先前選擇。玩家本次操作才會顯示選中狀態。

五家戲院卡片依使用者文案展示特色與完整說明；簡介置於名稱下、選擇鈕上，不截斷文字。已確認手機與桌面文字和按鈕不溢出卡片，且起始無預選。

旋轉木馬版已驗證：1600×1000、1024×768、390×844、320×568 的排列順序、左右切換、兩端停止、鍵盤及卡片點選、確認、無整頁水平溢出、重新整理無預選，以及手機觸控滑動。

手機緊湊版：提示固定為「請選擇你想經營的電影院」，選取及確定時都不改寫。上方確認區採橫向緊湊排列，手機約 64–67px 高；卡片高度依螢幕調整為 clamp(260px, 100svh - 320px, 480px)，短螢幕壓縮圖片但保留完整文字和觸控按鈕。已驗證 390×844、375×667、320×568 的五家戲院確認區、中央卡片及切換箭頭可在一個畫面內顯示。

手動選擇修正已驗證：桌面與手機的箭頭／方向鍵／圖片點選及原生觸控滑動只切換中央卡片，不自動選擇；手動按選擇後才顯示確認，再瀏覽時收起，重新按選擇可改選並確認。固定提示文案不變。

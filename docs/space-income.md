# 空間活化定價與入帳

實作於 activation-rules.js；狀態存入每局快照 activation，不重抽地點、權屬或空間類型。

## 調價窗口

初次設定當週可反覆調整；接下來三週灰色鎖定，第四週過後重新開放。例如W1設定，W2～4不可改，W5可調；W5改價則W6～8鎖定，W9再開放。若開放時未改價，不延長鎖定；之後實際改價才從該週起重新計四週。跨年使用連續絕對週，不在每年W1重設。

未有這項資料的舊存檔，以載入當週與原定價建立起點，不捏造過往收入。現有存檔驗證後續用原價、鎖定日期及收據；重新整理不重抽、不重複入帳。

## 收入公式

| 類型 | 未套定價懲罰的收入 | 入帳 |
|---|---|---|
| 商場櫃位 | 玩家月租金 | 初次設定四週後，之後每四週一次 |
| 娃娃機台 | 玩家月租金 | 初次設定四週後，之後每四週一次 |
| 電子看板 | 玩家每秒定價×1,296,000 | 初次設定四週後，之後每四週一次 |
| 停車場 | 玩家每小時定價×2×日觀眾人數×3×0.5 | 每週營運後，下一週入帳 |
| 電影院主題旅社 | 玩家每晚定價×4×2 | 每週營運後，下一週入帳 |

商場、娃娃機、電子看板W1設定，第一筆W5入帳；同價續用則下一筆W9。W5調價不回改已入帳的W5收據，新價第一筆W9；更晚調價則從改價週重新計四週後的下一筆，重啟月結週期，不另計未滿四週的部分期間。

停車場的日觀眾人數＝該營運週各片一般場已取整dailyViewers合計，包含票價、排片、行銷與special電影各自規則；不加入額外特別場人次。固定再乘3表示每週計三個營業日。旅社不乘觀眾人數。

## 高定價風險

適用全部五種活化類型：定價嚴格大於（min＋max）／2時，每次應結算收入各有50%機率為0；否則全額入帳，不做其他折扣。比較的是實際數值中點，不是可用step選項中位數，恰好中點不觸發。

| 類型 | 懲罰條件 |
|---|---|
| 商場 | ＞60,000 |
| 娃娃機 | ＞55,000（step2000，實際從56,000觸發） |
| 電子看板 | ＞1.75（step0.5，實際從2觸發） |
| 停車場 | ＞55 |
| 旅社 | ＞5,250（step500，實際從5,500觸發） |

使用每局種子＋活化類型＋入帳週產生固定抽選；收據保留定價、人數、是否零需求與整數金額。刷新、切頁不會重抽；有收入才四捨五入到元，0元收據也保留。月結類每四週抽一次，週結類每週抽一次。

## 財報

有活化空間時，週報新增以實際活化類型命名的收入列，顯示本週實際入帳，尚未到期為0；無活化空間不顯示該列。年報「其它」合計該入帳年度的活化收入；W50營運後於翌年W1入帳的週收入歸翌年。票房收據、餐飲、拆帳、稅與損益公式不混算。

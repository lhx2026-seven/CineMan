# 收支合計與稅前淨利

收入合計只計拆帳後電影票房、餐飲、海報、公仔與其它收入。拆帳前票房僅供顯示／TOP 5，不重複算收入。

支出合計為人事、商品成本、硬體維護、行銷宣傳、其它費用、公共事業帳單，以及租金／管理費／不動產稅。片租、片商比例及bomb保底已從拆帳後收入扣除，不再重列支出。

週報營業利益＝當週已入帳收入－當週已出帳支出。年報稅前淨利＝該年已入帳收入－該年已出帳支出。負值照實保留。年度會議顯示收入合計、支出合計與稅前淨利，與年報同源；年度損益扣除下述所得稅，與年報一致。

其它費用＝雜支＋實際特別場場數×5,000＋未另列支出名目的事件費用。特別場每場原本另有500元人事費，兩項分別列計，沒有互相取代。

事件記帳入口為CinemaOperatingExpenses.advance第五個參數eventExpenses陣列，各項{id,amount}；id代表唯一一次事件發生的識別碼，amount為正整數元。只傳入沒有其它支出名目的實際費用，同一發生識別碼僅可扣一次。租金、水電等繳費提醒不視為額外事件費用，避免重扣。目前未提供事件費用資料庫，當期事件支出為0，並無自行生成扣款。

舊operatingExpenses版本1紀錄缺少其它費用與歷史雜支時維持原值，從新結算開始記錄其它費用，不以本週預算回填。舊存檔歷史合計因此僅反映已記錄的收支；新局可完整逐週累計。

所得稅每週依當年已入帳合計重新計算，非每週重複扣款。2022–2025：(拆帳後電影票房＋純餐飲收入－餐飲成本)×5%＋拆帳後電影票房×7.5%；2026起僅保留前項5%。不含海報、公仔收入及製作費，餐飲成本取實際結算紀錄而非商品成本合計。負值照算並可抵減，最後四捨五入至元；年度損益＝稅前淨利－所得稅。W50歸屬結束年度，年度會議顯示完整50週，下一年度重新累計。舊存檔僅計已保存的歷史紀錄，不回填不存在的成本。未來事件的發生條件、決策與實際扣款金額仍待資料庫。

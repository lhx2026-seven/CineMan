# 餐飲與財報餐飲周邊收入

實作：concessions-rules.js；每局快照foodRevenue。財報「餐飲周邊」已整合餐飲＋海報＋公仔；本模組只計餐飲，周邊庫存及收入另由merchandise-rules.js結算，詳見merchandise-income.md。

## 已生效公式

```text
餐飲平均售價＝（爆米花售價＋飲料售價＋抽中時的獨家餐飲售價）／實際餐飲品項數
當週觀影總人次＝Σ（各片一般場單日已取整人次×3＋該片全部特別場已取整人次）
當週餐飲收入＝四捨五入至元（平均售價×當週觀影總人次×當週購買率）
```

沒有獨家餐飲就只平均2項，有則3項。海報、公仔的開賣勾選、數量及售價均不參與均價。無銷售權重、無額外購買品項數乘數，亦不依餐飲成本預算自行限制販售。

電影人次直接採該週已結算票房收據，已包含票價、區位、排片、行銷及0.1%保底等既有規則；這裡不重算上座率。一般場每日人次乘3天，特別場額外人次只加一次；含special電影，也含已營運後才於隔週下檔者。強制排除且票房收據人次為0的片不增加餐飲人次。

購買率每局每營運週抽一次，1%～90%端點皆含、步長1%，90個值等機率。以獨立種子concessions/v1/runId/earnedWeek/purchase產生，與片單、場地、活化收入及事件的抽選分離。保存於收據，刷新／Continue不重抽，同週所有電影共用購買率。

均價及推算購買人數中間保留小數，不先將「觀影人次×購買率」取整；最後收入四捨五入到元。例如兩品售價60元、1人、購買率1%，收入0.6元取整為1元。

## 入帳及保存

與票房相同，W1營運的餐飲收入於W2入帳，W1報表為0。W50營運收入於虛擬W51結算並歸當年年報，翌年W1不重複入帳。週報顯示該入帳週金額，年報加總入帳年度；年度會議的收入總額同樣納入已入帳餐飲。

收據保存營運週、入帳週、實際品項／售價、均價、觀影人次、購買率與整數金額。價格調整只影響之後的營運週；已入帳收據不回算。票房、活化與餐飲結算先各自產生下一份狀態，成功後才一起更新本局與存檔，避免部分入帳。

舊存檔沒有foodRevenue時從當週開始累計，不補算缺少當年售價與人次紀錄的過往餐飲收入。海報、公仔使用其獨立銷量公式，不套餐飲購買率；商品成本仍待其公式，不將未設定的支出視為已結算的0元。

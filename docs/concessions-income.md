# 餐飲與財報餐飲周邊收入

實作 concessions-rules.js，存檔 foodRevenue。財報餐飲周邊包含餐飲、海報與公仔；本模組只計餐飲。

餐飲均價＝爆米花、飲料、抽中時的獨家餐飲售價平均。海報與公仔排除。
週觀影人次＝各片一般場單日人次×3＋特別場人次，使用已結算票房收據，不重算上座率。

## 新購買率規則

按以下優先順序，命中即停止：

1. 人力預算＜影廳數×4,000：購買率固定10%。
2. 餐飲成本＜餐飲均價×週人次×10%：隨機1%～10%。
3. 餐飲成本＜餐飲均價×週人次×33%：隨機11%～20%。
4. 其餘：隨機30%～60%。

門檻嚴格小於，等於不觸發該級。33%是精確0.33，不是三分之一。隨機端點皆含、步長1%、等機率，每局每週抽一次，獨立種子 concessions/v2/runId/earnedWeek/purchase；刷新不重抽。人力不足固定10%優先於成本不足。

整體一般場上座率＝所有影片一般場單日人次合計／（總座位數×6）。特別場不計此比率，仍計餐飲消費人次。
上座率嚴格＞90%加30個百分點；否則＞70%加20個百分點；否則＞50%加10個百分點；其餘不加。只取最高級、不累加；等於門檻不觸發該級。成本不足或人力不足的基礎購買率也適用。
最終購買率＝基礎購買率＋上座率加成，之後再套行銷倍率。

餐飲行銷倍率＝1＋floor（行銷費／10,000）×10%。原行銷規則繼續套用於上述購買率，因此10%固定指加成前購買率。
餐飲收入＝四捨五入至元（餐飲均價×週人次×購買率×餐飲行銷倍率）。
新規則取代舊成本不足銷量減半、10%人次封頂；不得再重複套舊懲罰。中途人次、均價不取整，只取整最後收入。

## 保存與入帳

新收據 ruleVersion=4，保存當年度累積餐飲成本（annualFoodCost），另保存總座位數、一般場單日總人次、基礎購買率整數百分比、上座率加成百分點；保存當週人力預算、實際影廳數、餐飲成本、行銷費、購買率、品項售價、人次、均價和金額。讀檔驗證對應購買率範圍。版本2收據不補上座率加成；沒有 ruleVersion 的舊收據依原公式驗證並保留，不回算歷史金額。舊收據缺行銷費按0，缺餐飲成本不套舊成本懲罰。

W1營運收入於W2入帳；W50於年度會議入帳並歸當年，不重複入帳。缺歷史餐飲帳本時不補算缺資料的過往收入。海報、公仔仍使用各自公式。

驗證：tests/concessions.cjs、tests/concessions-browser.cjs。

## 年度零成本限制

當年度累積餐飲成本（含本週）為0，該週餐飲收入強制為0，優先於購買率、上座率及行銷加成。每年50週，依營運週所屬年度重算；W50於年度會議入帳仍歸舊年度。年內曾有餐飲成本支出後，即使本週成本為0，仍照既有購買率規則計算。只含foodCost，不含海報、公仔製作成本；海報及公仔收入不受本限制。已入帳舊版收據維持原金額，不回溯改寫。

# 排片策略版型

## 本週新片

兩張新片卡以有限範圍的 3D carousel 呈現，起始中軸位於兩片之間，卡片對稱且兩個選擇按鈕皆可用鍵盤抵達；選定後或瀏覽單片時才移動中軸，可用左右箭頭、左右滑動、方向鍵／Home／End 或點側邊卡片瀏覽；瀏覽不自動選取。只有卡片「選擇」按鈕才將該片設為本週主打，選中後亮起。支持減少動態效果。

初始未選主打片，場次占比整區隱藏，下一週維持停用。選中後下方顯示「選擇XX為本週主打，場次占比」及百分比滑桿，以每週 `6 × 本局廳數` 個整數場次為容量，每格 1 場，即 `100% / (6 × 廳數)`；範圍 0–100%。瀏覽另一片不改變已選主打片。新局初始為比 100% 少一格的最高比例，即 `(6 × 廳數 − 1) / (6 × 廳數) × 100%`，例如 1 廳 83.33%、3 廳 94.44%；保留已存比例。說明文字與即時百分比相連、整體置中，保存 `featuredSlots` 整數，不保存四捨五入的百分比。畫面最多顯示兩位小數；舊版 `featuredShare` 百分比存檔會轉成最接近的合法場次。

MoviesList 與海報尚未提供，正式頁目前使用「新片 01／02」占位卡及裝飾性海報框，沒有虛構電影資料或向不存在的 MoviesList 發請求。不提供片型、演員、熱度等額外電影資訊。之後只替換海報與片名。

`CinemaFilms.pickNewMovies(eligiblePool, seed)` 已預留可重現的等機率抽樣工具：傳入正規化的候選新片陣列（各筆至少有唯一 id、title），排除三部固定舊片，再不放回抽取兩筆。少於兩部或 ID 重複會報錯，不以重複電影補足。MoviesList 提供後，仍需依實際欄位建立當週可選池並接入此工具及版型；同一局同一週應使用穩定的種子，不因重整換片。

## 固定舊片

W1 固定呈現以下三部，不參與新片隨機抽樣；例外：實際分派僅 1 廳時，首週三部皆不上映，上映區與特別場選單一併排除：

| ID | 片名 |
| --- | --- |
| MV0001 | 魔猴 |
| MV0002 | 恐怖速食店 |
| MV0003 | 酆都 |

使用者已指定酆都（MV0003，簡寫 MV003）於 W2 固定下片；魔猴、恐怖速食店（MV0001／MV0002，簡寫 MV001／MV002）從 W3 起與其他仍上映電影共同參與隨機下片。不得當成 W3 必定下片，也不能只抽這兩部舊片。

`retirementPool(showing, week)` 提供固定下片清單與 W3 起的共同候選池；`drawRetirements(showing, week, count, seed)` 可在明確指定下片數量後不放回等機率抽選，保留可重現種子。每週隨機下片數量尚待確認，不設任意預設。此為週進程接入用的規則工具，現行遊戲仍停在 W1 版型，待 MoviesList 與週進程接入後同步更新片單及特別場選項。

## 特別場

世紀（C02）與公會堂（C05）停用特別場：隱藏且停用整區，舊存檔的特別場設定不再啟用，新存檔不保存此功能欄位。其餘三家特別場每週上限五場，初始只顯示第一場的選片下拉選單。選好後顯示單一票價與「加一場」，按下後展開下一場；第五場不再顯示新增按鈕。各場可選當週上映的電影（可重複選片），清空選片則隱藏、停用該場票價。使用 specialCount 保存已展開數量，第一場沿用 specialMovie／specialPrice，相容舊存檔；後續使用 specialMovie2–5／specialPrice2–5。此為介面與配置，影廳分派、成本、收益與排片衝突公式尚未設定。

同一局重新整理可還原主打片、占比、特別場下拉選片與價格，並回到已選主打片所在 carousel 位置。新局依既有規則不沿用上一局配置。

## 驗證

`node tests/films.cjs` 檢查 10,000 次雙片抽樣的不重複、排除固定舊片、可重現、均勻邊際頻率與來源資料不被修改。

Playwright／Chromium 瀏覽器測試：`CINEMAN_BASE_URL=http://127.0.0.1:8000 node tests/film-strategy-browser.cjs`。已在 320／390／768／1440px 驗證瀏覽不選取、手動選主打後顯示與解鎖、占比調整、三部固定舊片 ID、特別場下拉選片與票價、重整還原、鍵盤瀏覽及無額外電影資訊／水平溢出。

`CINEMAN_BASE_URL=http://127.0.0.1:8000 node tests/special-screenings-browser.cjs` 驗證逐場新增至五場、保存與還原、裝飾線移除、單廳首週舊片排除及手機／電腦無溢出。

特別場版型：寬螢幕可並排五場，每場片名在上、票價在下；中等寬度自動換行，380px 以下改為每場一列、片名與票價左右排列，避免欄位過窄。每場標示場次編號，新增與存檔欄位不變。

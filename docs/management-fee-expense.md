# 管理費

限布洛威（C03）與YLC（C04），自有與承租均收費。每局從400、450、500、550、600等機率抽一個係數，管理費＝四捨五入至千元（總座位數×係數）。係數、計算時座位數及金額保存後不調整，每次出帳沿用同一筆已取整金額。

W4第一次收費，之後每4週一次；絕對週次4、8、12…跨年接續。每年50週，所以2022最後W48、下一次2023 W2。虛擬年度會議不多出帳單。

週報／年報「租金、管理費、不動產稅」支出欄加總三者。當週出帳時，租金及管理費合併提醒「本週繳交租金及管理費」；自有僅有管理費則「本週繳交管理費」。提醒改依實際管理費紀錄，不再從Parameter.manage_fee的舊範圍或週期另作推算。

新快照managementFee版本2保存取整金額，版本1既有固定費用與歷史帳單維持原值，不重算。快照保留版本、戲院／局ID、座位數、係數、固定金額、處理週次與帳單；重新整理／續玩不重抽、不重扣。舊存檔首次載入建立係數並補列截至當週的到期帳單，既有租金、不動產稅及收入不回算。

程式management-fee-rules.js；tests/management-fee.cjs、tests/payment-reminders.cjs、tests/rent-browser.cjs與年度／進場相關測試涵蓋係數分布、適用戲院、自有、金額、每4週、跨年、會議、存檔固定及防重扣。
